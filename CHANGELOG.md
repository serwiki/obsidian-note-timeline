# Changelog

## 0.2.0 — 2026-10-31

- Browse notes and folders using a searchable, expandable explorer-style tree.
- Set the number of preview lines (1–30).
- Show or hide the Modifications tab.
- Browse plain-text dates and tracked file activity in side or main calendar views.

## 0.1.0 — Initial prototype

- Calendar for plain-text dates.
- Index Markdown notes, display session excerpts and jump to source locations.
- Insert the current date using a configurable format.

> The changelog describes prototype features, not formal cross-platform certification.
