# Contributing

Thanks for your interest in Note Timeline.

## Reporting issues

Include your Obsidian version, operating system, plugin version, reproducible steps, and expected versus observed behavior. Please **do not upload real classroom notes or private vault data**. Use synthetic text instead.

## Development

1. Install an active Node.js LTS version.
2. Run `npm install` and `npm run build` in the repository root.
3. Test changes in a disposable Obsidian vault.
4. Include clear reproduction steps and screenshots (without private notes) for UI changes.

Please keep the plugin offline-only and avoid dependencies on desktop-only Electron/Node APIs in runtime code.
